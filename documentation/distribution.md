## Rights and licensing

The repository's source code is licensed under the [MIT License](../LICENSE). This does not grant rights to the original WARC files, news articles, images, or original content included in the derived dataset. Third-party components retain their respective licences.

| Material | Licence status |
| --- | --- |
| Project source code | MIT License. |
| Dataset metadata | No separate licence has been assigned. |
| News text and images | No reuse licence has been established by this project. Images may have rights holders distinct from the newspaper. |

Access to archived material does not itself establish permission to republish it or use it for model training. A formal dataset rights statement and takedown procedure remain to be established.

## File formats

| Material | Format |
| --- | --- |
| Article records | UTF-8 JSON using the project's ninjs 3.2 profile; one file per article. |
| Images | Original archived image formats, such as JPEG, PNG, GIF, and WebP. A complete format inventory is not yet available. |
| Optional search database | SQLite, generated by the display tools; not confirmed as a release resource. |
| Processing reports | TSV reports and JSON summaries. |

Historical combined article files may use JSON arrays or JSON Lines. The resources included in a formal release should be listed on its dataset page.

## Citation

The formal dataset citation will be provided when the creators, publisher, release version, year, access URL, and persistent identifier are confirmed.

For the code, record the repository, tag, commit, and access date:

```text
jimmy93029/appledaily_warc_file_scrawler,
dataset-v3, commit 4acdaa1, accessed YYYY-MM-DD.
```

Code and dataset citations should be kept separate.
