# Apple Daily Taiwan Dataset Documentation

This documentation describes a research collection of Taiwan Apple Daily news text, metadata, and images extracted from archived web pages. It explains what the data contains, how it was produced, and the limits of its use.

## Publication status

The code is available under the MIT License. This does not license the original news content. The formal datasheet is planned for depositar; the final dataset access URL, publisher, data licence, persistent identifier, release checksums, and maintenance arrangements remain to be confirmed.

Technical and administrative enquiries can be directed to the [designated contacts](distribution.md#point-of-contact). Code behavior and historical statistics are documented, but full-release validation is not yet available. Unconfirmed information is identified where relevant.
