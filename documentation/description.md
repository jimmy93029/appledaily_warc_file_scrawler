# Dataset description

Parent: [Dataset documentation](README.md)

The **Apple Daily Taiwan Web Archive Dataset** contains news text, metadata, and associated images extracted from ArchiveBot captures of the Taiwan Apple Daily website. It turns archived web pages into article-level ninjs JSON records for preservation and research after the source website became unavailable.

## Scope

| Item | Description |
| --- | --- |
| Publication-year coverage | 2003–2022 as documented; exact boundaries for a formal release have not been audited. |
| Geographic context | Taiwan, with international news coverage. No normalised item-level geographic coverage is supplied. |
| Content | Politics, society, local news, finance, entertainment, sport, lifestyle, and other website sections. No controlled topic inventory has been published. |
| Intended audience | Researchers in digital humanities, journalism, information retrieval, NLP, and digital preservation, as well as educators and students. |
| Dataset homepage | A formal datasheet is planned for depositar; its final URL is pending. See [access and publication](distribution.md#access-and-publication). |

The collection is reconstructed from web captures and does not claim complete coverage of the newspaper's historical output.
